IIH Presales Hub — release v3.1.0
=================================

UPLOAD (2 minutes)
1. Open the folder UPLOAD_TO_GITHUB. Inside it you see: index.html and a folder named js.
2. On GitHub, open the repository's MAIN page (github.com/IIH-Projects-Management/presales-hub),
   NOT the js folder, and click  Add file → Upload files.
3. Select BOTH  index.html  and the  js  folder (from INSIDE UPLOAD_TO_GITHUB) and drag them together
   onto the upload area. Do not drag UPLOAD_TO_GITHUB itself.
4. Wait until all 7 files are listed (index.html + 6 files under js/), then click the green
   "Commit changes" button at the bottom and wait for the file list to reappear.
5. Wait 1–2 minutes, open the hub, press Ctrl+Shift+R (Cmd+Shift+R on Mac).

CHECK
- Open "How it works": the heading must show  v3.1.0.
- A product page shows "✎ Edit product" (Leadership) and it opens the editor.
- The "Client engagements" tab is there.

Unchanged and NOT included: js/firebase-config.js, js/catalog.js, js/docgen.js, assets, videos.
